# CyberVerse Recovery Tracker

This tracker is intentionally initialized with no assumed defects. Add a finding only after it is supported by source or runtime evidence.

## Status definitions

- **Open:** Verified finding, not yet scheduled.
- **Planned:** Remediation approach agreed.
- **In progress:** A focused fix is being implemented.
- **Ready for verification:** Code change complete; tests pending.
- **Verified:** Required tests passed and regression risk reviewed.
- **Blocked:** Requires unavailable source, credentials, provider, environment, or owner decision.
- **Closed:** Verified and documented.
